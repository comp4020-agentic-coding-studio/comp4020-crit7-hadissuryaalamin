# Crit 7 reflection

## What was the breakthrough that moved the work forward?

The breakthrough was changing my harness before the work started. I changed
my course-wide `CLAUDE.md` so caveman mode is always on, replaced my old
pm-discovery skill with the brainstorming skill for the discovery step, and
added a rule for choosing the model: Opus for planning and judgment, and not
Opus when executing the plan, so the build runs on Sonnet and saves tokens.

The second breakthrough was about the look. I kept wondering how to make a
web UI that doesn't feel like AI slop, so I browsed the available skills and
found the Impeccable skill. It was really useful: it gave me a choice of
visual directions on a page in the browser, with things like the colour
palette shown for each one, so I could see what my site was going to be
before any code was written, and then pick one.

## What did this work change about who I want to be as a software developer?

As a developer today, I need to think first and write my prompts with
structure. It helps a lot to understand how the workflow works in practice
and how AI agents actually behave. Better planning also saves a lot of cost:
when I put the details and the constraints into the instructions, I can
drive the agent correctly instead of paying for it to guess and redo work.
